# HTMAA F26 Source Code

Welcome! 

This repository contains all of my source code for my weekly and final project of the "How to Make (Almost) Anything" class at MIT (Fall 26). It is organized per week, and is meant to be a collection of the entirety of the code written during this class.

For reference, you may want to visit the [class website](https://pub.cba.mit.edu/863.26/site/) as well as my [personal website for the class](https://pub.cba.mit.edu/863.26/alexandre.bismuth/index.html)!
