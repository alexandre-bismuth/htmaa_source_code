# forza-MIT: gameplay media

forza-MIT is an HTMAA final project: a Forza-Horizon-style driving game in Unreal Engine 5.8 on the real MIT / Cambridge map (City of Cambridge GIS and 3D data), where you drive a 2002 Subaru Impreza WRX STi in a blue WRC livery with "HTMAA" plates through timed laps and sprints around campus.

All media below were captured in-engine from the current version of the game (2560x1440 stills, JPG; clip at 1920x1080 60 fps with in-game engine audio).
